# Research references

These sources inform the roadmap and audits. They are references, not redistributable game assets.

- `modernization-outline.pdf` and its extracted `modernization-outline.txt`: supplied project modernization brief.
- [OneShortEye, “Why (almost) No One Solves this Game”](https://youtu.be/nSODB1CRez0): issue analysis supplied by the project owner; its ending investigation begins around 3:22:16.
- [OneShortEye, *Dagger of Amon Ra – Point System*](https://docs.google.com/spreadsheets/u/1/d/e/2PACX-1vQcD2Kf82D1qVfUpYr8y1UETufctxAvZN6FFfUhAKSve44cgpBd8MCMWGoPwnQVOr_4NXzuxg46aQe7/pubhtml): published flag-by-flag scoring audit linked from the video and independently checked against the source for P4-05.
- [Sierra, *The Dagger of Amon Ra* hint book](https://www.sierragamers.com/wp-content/uploads/2019/12/Laura_Bow_2_Dagger_Of_Amon_Ra_Hint_Book.pdf): official evidence and inquest guidance used for P4-03.
